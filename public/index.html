KFC Crazy Thursday API

无论你问什么，答案永远是疯狂星期四

API Base URL

将你的 OpenAI 客户端 API 地址设置为：

支持的模型

  • kfc-crazy-thursday 默认
  • kfc-original-recipe
  • kfc-spicy-wings
  • kfc-bucket-meal

使用示例

curl -X POST $(echo $API_URL)/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "kfc-crazy-thursday",
    "messages": [{"role": "user", "content": "你好"}],
    "stream": true
  }'

特点

1. 支持流式 (SSE) 和非流式响应
2. 兼容 OpenAI Chat Completions API
3. 无需 API Key
4. 随机 KFC 疯狂星期四文案
